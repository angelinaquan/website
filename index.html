Dataset Distillation via Drifting
George Cazenavette, Angelina Quan, Giannis Daras, Antonio Torralba, Vincent Sitzmann

Dataset distillation builds a tiny set of synthetic images so training matches a large real dataset; most prior work assumes a randomly initialized network, while practice now relies on big pretrained vision backbones. This work distills data for training linear probes on frozen features via Linear Gradient Matching—synthetic images are optimized so their induced gradients in the linear classifier match those from real data. The resulting images beat real-data baselines, transfer across pretrained architectures (e.g., distilling with a DINO backbone still yields a strong CLIP linear probe), and help fine-grained classification, interpretability, and analyses of embedding similarity and spurious-correlation sensitivity.

Edamame
Angelina Quan, Ella Lan, James Liu, Videet Mehta (in no particular order)
Treehacks 2026
project page

Edamame tackles lost institutional knowledge: when people leave, context disappears; when they join, tribal knowledge is buried across Slack, Drive, email, and more. The system builds a cited, continually updated digital twin per employee by ingesting Slack, Google Drive, Gmail, GitHub, Notion, and Jira via real OAuth—so you can ask a clone (text or voice) and get answers grounded in sources, not guesses. Ship highlights include clone chat with personality and live memory extraction, a management view that polls every clone for strategic questions with confidence and themes, auto-generated onboarding briefs, and offboarding handoff packs; built at TreeHacks 2026 (Next.js, React, Supabase/pgvector, GPT-5.3, Whisper/TTS), Greylock award for best multi-turn agent.
